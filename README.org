* What this is

A personal work-time tracker that accrues hours against a 37 hour week, records presence from operating system lock and sleep events, and presents the result with as little encouragement as possible.

It began as four lines of PowerShell that hibernated a laptop at 18:00. That behaviour is being restored as a feature.
